OpenLoch – Help

OpenLoch designs perfboards and stripboards. Its handling and files follow LochMaster 4: projects are saved as .LM4, templates and libraries are read and written as .LMB and .LIB.

Getting started

  1. File → New board… creates a board; File → Open… loads a project, a template, a library or a backup file.
  2. Choose a page in the component panel on the left, click a component and click on the board or drag it there. Components snap with their reference point onto a hole.
  3. Use the tools on the left for wires, leads, solder joints, strip cuts and drill holes.
  4. File → Save writes the project as .LM4 like LochMaster. OpenLoch's own .openloch format can be chosen under “Save as…”.

Board

Board → Properties… holds the name and size, the hole pitch of the unit N, the snap grids of the units mm and inch, the origin, the offset between board and copper and the board's extra fields. A project can hold several boards; they appear as tabs below the drawing area. Adding, duplicating, renaming, ordering, turning and deleting are in the Board menu and in the tabs' context menu.

Edit layout… opens the board's copper (strips, pads, holes). The Origin tool sets the zero point of the rulers and the grid.

Drawing

The tool palette on the left holds, from top to bottom: select, zoom, lines, circle, rectangle, polygon, text, wire, pin, lead, solder joint, strip cut, drill, potential, continuity tester, origin and pad. Lines and polygons are set point by point and finished with Return or a double click; Esc or a right click ends the tool.

Like the original, choosing a tool sets its colour and width: wires silver at 0.4 mm, lines and areas black at 0.1 mm, pins white at 0.6 mm, texts black on yellow.

Objects snap to the grid of the chosen unit, counted from the origin: in N to the hole pitch, in mm and inch to their grids. Holding Shift places without snapping. Wires also snap to terminals and holes.

Components and library

The library holds all pages of the LochMaster library, drawn anew, and pages with modern components. Own pages are created with Library → New page…; Component → Add to library… first opens the component dialog and then puts the marked objects onto the current page as one component. Library → Properties… shows the page's name, file and extra fields; “Properties…” in the list's context menu edits the marked component.

Component → Create component… turns several objects or a group into a component with name, identifier, value, description and extra fields. Identifiers with # (such as R#) get a running number; Component → Renumber numbers them anew in the order of the document, also inside other components. A double click in the object tree opens the properties, also those of a nested component.

The Wizard… creates components and outlines from dimensions. Owners of LochMaster can show its libraries as well with Library → Connect LochMaster libraries…; they are only read. The component folder (Documents/OpenLoch/Bauteile) keeps each component as a file of its own; subfolders appear as pages.

Edit and arrange

Edit holds undo and redo, the clipboard, duplicate, select all, delete, properties and outline nodes. Undo steps… sets how many steps can be undone (1 to 50).

Arrange holds bring to front and send to back, move to the other board side, group and ungroup, align (left, right, top, bottom, centre vertically, centre horizontally, component pins to board holes), rotate (90° right, 90° left, 180°, angle…) and mirror (horizontal, vertical). A right click on an object opens the same commands as a context menu.

Colours, width, fill, outline

The toolbars at the bottom act on the marked objects and on new ones:

  • Colours: the left mouse button chooses the line colour (FG), the right one the fill colour (BG).
  • Width: swatch for the line colour and the line width from “invisible” to 2 mm.
  • Fill: swatch for the fill colour, “Fill areas” and the buttons BMP (load a bitmap fill, also PNG, GIF and JPEG) and ROT (turn the bitmap fill).
  • Milling: normal outline or milled outline.
  • Outline: original outline, B-splines, chamfers and roundings with a chosen size.

View → Show toolbars shows and hides each toolbar.

View

View → Options holds the switches of each board: B/W display, flip (the board seen from below, turned top to bottom), see-through (edit the solder side without mirroring), x-ray view (the other side shown faintly), BMP rendering (bitmap fills and solder joints with a 3D picture), show potentials and smooth fonts. Rulers / grid chooses the unit N, inch or mm and shows the rulers; the button in the rulers' corner switches the unit (Ctrl+<). Zoom holds zoom in, zoom out, fit, zoom objects, zoom selected objects and real size 1:1.

Checking

The continuity tester marks everything connected to the clicked copper. Potential markers give nets a name and a colour; “Show potentials” colours the nets. The Free areas button shows copper without any terminal while it is held. Check → Check for shorts finds nets that join different potentials.

Components list and notes

Board → Components list → Create… shows the components list, the shopping list and the jumpers; “Create Excel sheet…” opens the table in the spreadsheet program and also puts it on the clipboard. Board → Notes… opens a text editor with formatting; parts and shopping lists can be inserted at the caret.

Print, export, backups

File → Print… opens the print preview with up to ten views per board, layers, scale, position, tiles, cut marks and correction factors. File → Export writes pictures (BMP, JPG, PNG), PDF, HPGL files for drilling and milling, component libraries, board templates and the components list as CSV.

When an LM4 file is opened, OpenLoch keeps a copy <name>.OLD like the original. File → Auto save… backs the project up at a chosen interval as <name>.BAK next to its file; an opened .BAK file becomes the project again. OpenLoch also keeps unsaved changes for recovery after a crash.
