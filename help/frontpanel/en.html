Front panel – Help

The front panel editor designs front panels for enclosures: holes, cut-outs, lettering, scales and symbols, for printing, as a graphic and as HPGL files for milling and engraving machines. Operation and files follow FrontDesigner 3: projects (.FPL) and library pages (.LIB) are read and written; the own format is .olfp. In a project of the suite the front panel belongs to the project (.openloch).

First steps

  1. File → New… asks for the name, size and colour of the front panel. Front panel → Add… adds more front panels to the same document; each has a tab above the drawing area.
  2. Choose a tool on the left and draw on the front panel. All points snap to the grid; Shift turns snapping off. Options → Grid… sets the grid size, snapping and the origin.
  3. Symbols come from the library on the right: click one, it hangs at the mouse pointer, and a click places it.
  4. File → Save saves; Save as… chooses the format (.olfp or the FrontDesigner project .FPL).

Tools

Rotate, ZoomTurn the selection freely (snapping to 45°, Shift turns it off); enlarge an area.
Line, AreaPolyline and closed area point by point; the right mouse button ends them.
Rectangle, Circle, ArcArc: centre, start and end clockwise.
PolygonRegular polygon with number of corners, inner or outer radius and start angle.
Text, Drill holeLettering; a hole with the diameter set.
Scale assistant, Panel cut-outSee Scales, cut-outs, dimensions.
DimensionTwo measuring points, then the position of the dimension line.
Import picture, Set originInsert a bitmap or a vector graphic (EMF); set the zero point of the coordinates.

The right mouse button leaves a drawing tool, cancels placing and otherwise opens the context menu; on a node it adds or deletes nodes.

Editing and arranging

  • The arrow keys move the selection by one grid step, with Shift by 0.1 mm.
  • Arrange: make and dissolve groups and combinations (areas with cut-outs), bring to front or send to back, align (to the object selected last, a single object to the front panel), distribute, align to the grid, mirror.
  • The bars at the bottom: align, rotate by the angle step set, width and height (without a selection those of the front panel), contour (corners as drawn, smoothed with B-splines, chamfered or rounded, with a size), display of the layers and position from the origin.
  • Edit → Apply properties applies pen, fill or font to the selection; Properties… opens the dialog of the object.
  • The Object tree (Options) shows the parts of groups; there they can be selected and edited one by one.

Pen, fill, font, view

The sidebar on the right has five pages: Symbols, Pen, Fill, Font and View. When exactly one object is selected, they take over its settings for the next objects.

  • Pen: colour, width, line style and tool. The tool (pen, milling cutter, engraver) decides what goes into the HPGL files.
  • Fill: plain, hatched or a gradient.
  • Each page keeps a list of saved presets to add, delete and order. Options → Take over presets from FrontDesigner… reads the lists of the original.
  • View: zoom in and out, show everything and the saved views of the document.

Texts and stroke fonts

  • Outline fonts (TrueType) are drawn filled, stroke fonts (SHX) as single lines for engraving.
  • In the text dialog, SHX… shows the characters of the chosen stroke font; a click puts the character into the text at the cursor.
  • Options → Install stroke font… takes SHX, SHP and FHX files. Like FrontDesigner, OpenLoch reads their characters in the DOS order; Character order of the stroke fonts… switches single fonts to Windows.
  • Fonts used… lists the fonts of the document. When one is missing, the overview opens by itself on loading, and the texts appear in a substitute font until then.

Scales, cut-outs, dimensions

  • The Scale assistant makes straight and round scales with linear or logarithmic division, scales of dots, empirical and two-sided scales. Its settings can be saved and loaded (.SCL).
  • The Panel cut-out draws the frame and the opening of a panel instrument: after DIN 43700 or with own sizes, round or rectangular, milled inside with the cutter width, with mounting holes if wanted. Its settings can be saved as .CUT.
  • The properties of a scale or a cut-out open the assistant again; the object is made anew in its place.
  • Options → Dimension defaults… sets the font, lines, arrows and decimals of dimensions.

Library

  • The Symbols page shows one library page; the list above it changes the page. Own pages are kept in the folder Documents/OpenLoch/Frontplattensymbole.
  • Library → Add to library… takes the selection with a name and an insertion point. The context menu of a symbol offers properties (change name and insertion point), renaming, reordering and deleting, and creating, renaming and deleting pages.

Boards behind

In a project of the suite the front panel knows the boards of the perfboard and circuit board documents:

  • Front panel → Boards behind… puts boards behind the front panel (offset, rotation, side facing it).
  • Show boards draws them over the front panel for checking, never in printing or export.
  • Holes from the board… places holes above LEDs, potentiometers, switches and sockets; Compare with the board finds holes whose part is no longer under them.

Printing and exporting

  • File → Print… with a preview: layers, original size or a scale, normal or mirrored (for foils), tiles, cut marks, a single sheet, copies and correction factors for true-to-size prints.
  • File → Export → Graphic… writes PNG, JPG or BMP at a chosen resolution, EMF or PDF as vectors.
  • File → Export → HPGL machining files… writes the drilling, milling and engraving for the machine.

Files and backups

  • Formats: .olfp (own format), .FPL (FrontDesigner project), .LIB (library page), .BAK (backup; it opens as the project it belongs to).
  • File → Auto save… writes a backup beside the project at an interval you choose.
  • Files dropped on the window are opened or inserted as a picture.
